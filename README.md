# Restaurant Demand Forecasting and Smart Inventory AI

An educational machine-learning project that forecasts restaurant food demand and supports ingredient inventory management.

## Features
- Demand forecasting for Pizza, Burger, Pasta, and Biryani
- Random Forest machine-learning models
- Model evaluation using MAE
- Ingredient requirement calculations
- Stock shortage detection
- Supplier lead-time and expiry-priority reports
- Interactive Streamlit dashboard
- CSV report downloads

## Technologies
- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib
- Streamlit

## How to Run

Install dependencies:

    pip install -r requirements.txt

Launch the dashboard:

    streamlit run app.py

## Dataset
The initial dataset is synthetically generated for demonstration.
Real restaurant data is needed to evaluate practical forecasting accuracy.

## Disclaimer
This is an educational prototype, not a validated commercial system.
